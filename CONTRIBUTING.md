Welcome to the list of awesome GitHub profile readme templates and thanks for considering to contribute. Contributions are welcome so we can tap into the collection of best Github profile readmes' and create a place where people can find the best resources to create their own profile README.

Please [open a pull request](https://github.com/cid-kageno-dev/awesome-github-profile-readme-templates/pulls) if you would like to contribute new or improve existing readme. If you would like to create an issue, please do so.

This is a curated list so the goal is not to collect all possible resources but collect the ones which are most helpful, provide a unique perspective, or are of special significance.

## How to contribute:

### Step 1: Fork this repository
Click the "Fork" button in the top-right corner of this repository to create a copy under your GitHub account.

### Step 2: Clone the repository in your local machine
```bash
git clone https://github.com/YOUR-USERNAME/awesome-github-profile-readme-templates.git
cd awesome-github-profile-readme-templates
```

### Step 3: Create a new branch
```bash
git checkout -b add/your-github-username
```

### Step 4: Create a new markdown file
Your file name should be your GitHub username.

```
File name format: username.md
Example: john-doe.md
```

⚠️ **Important:** File names should be lowercase with hyphens (if needed), not spaces or underscores.

### Step 5: Copy and Paste your GitHub profile readme content in the new file
- Put the file in the **templates** directory
- Include your complete GitHub profile README content
- Make sure all images and links are working properly

```
templates/your-username.md
```

### Step 6: Add footer information to your template
At the end of your template file, add the following content with appropriate changes:

```markdown
------

**Credit:** [your-username](https://github.com/your-username)

**Last Edited on:** DD/MM/YYYY

```

- Add line break using `------`
- Credit: Your GitHub username with a link to your profile
- Last Edited on: Date when you edited/created this file in DD/MM/YYYY format

**Example:**
```markdown
------

**Credit:** [john-doe](https://github.com/john-doe)

**Last Edited on:** 02/06/2026
```

### Step 7: Add your name and filename in `_sidebar.md`
Edit the `_sidebar.md` file and add your template reference in the appropriate alphabetical section:

```markdown
- [your-username](/templates/your-username.md)
```

**Important:** Maintain alphabetical order within each letter section.

### Step 8: Verify your changes locally
Before committing:
- ✅ Check that all links in your template work
- ✅ Verify all images display correctly
- ✅ Ensure markdown formatting is valid
- ✅ Confirm the filename matches your GitHub username

### Step 9: Commit your changes with a proper message
```bash
git add .
git commit -m "Added template for username: your-username"
```

Your commit message must contain your GitHub username for better tracking.

### Step 10: Push your commit to GitHub
```bash
git push origin add/your-github-username
```

### Step 11: Create a Pull Request
1. Go to your forked repository on GitHub
2. Click "Compare & pull request"
3. Add a clear title and description
4. Click "Create pull request"

### Step 12: All Done!
Your PR will be reviewed by the maintainers. If there are any issues, they'll let you know. Once approved, your template will be merged! 🎉

## 📋 Contribution Checklist

Before submitting your PR, please ensure:

- [ ] File is in `/templates/` directory
- [ ] File name is your GitHub username in lowercase with `.md` extension
- [ ] File contains your complete GitHub profile README
- [ ] All links and images are working
- [ ] Footer section includes Credit and Last Edited on
- [ ] Entry added to `_sidebar.md` in alphabetical order
- [ ] Commit message includes your username
- [ ] No sensitive information is included
- [ ] Template follows Markdown best practices

---

## 📝 Quality Guidelines

Your template should:

1. **Be Original or Attributed** - If based on someone else's work, provide proper credit
2. **Follow Markdown Standards** - Use proper markdown syntax
3. **Have Working Links** - All URLs and references should be valid
4. **Be Well-Formatted** - Easy to read and understand
5. **Showcase Skills** - Highlight your unique profile approach
6. **Be Reusable** - Help others understand and adapt it

---

## 🚫 What NOT to Include

- ❌ Personal contact information (phone numbers, addresses)
- ❌ Sensitive API keys or tokens
- ❌ External links to other profile collections (unless directly relevant)
- ❌ Broken or non-functional links
- ❌ Inappropriate or offensive content
- ❌ Spam or promotional material
